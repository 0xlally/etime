# ETime v1.0.4

本次发布更新计时工作台并简化项目部署文档。

## 更新内容

- 优化计时页桌面与移动端布局，加入北京时间和桌面看板娘。
- 将常用卡片管理集中到分类管理弹窗，并统一操作图标样式。
- 停止计时按钮默认保持黑色，仅在鼠标悬停时显示红色警示。
- 修复看板娘在移动端和 React 开发模式下的挂载清理问题。
- README 移除界面截图，保留公网入口、服务器部署和 Android 构建说明。

## Android

- 版本：`1.0.4 (104)`
- 安装包：`etime-v1.0.4-release.apk`
- 使用 v1.0.3 起启用的新签名证书，可从 v1.0.3 直接覆盖升级。

自律模式需要手动授予 Android“使用情况访问”和“悬浮窗”权限。

## 验证

- TypeScript 与 Vite 生产构建
- 计时页桌面和移动端视觉检查
- Capacitor Android 同步
- Gradle 签名 Release 构建
