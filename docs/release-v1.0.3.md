# ETime v1.0.3

本次发布集中完善复盘工作流、年度数据视图和通知体验。

## Highlights

- 新增每日、每周、每月、每年四种复盘范围，年度复盘按月展示全年节奏。
- 所有复盘范围支持查看全部分类，或组合筛选多个分类。
- 全年热力图增加 1-12 月时间线，并与每日热力格同步滚动。
- 评估记录从计划页迁移到复盘页，复盘信息集中展示。
- 修复宽屏侧栏通知弹层被裁剪的问题；打开通知后可一次性清除全部未读状态。
- 删除独立 Markdown 预览和独立分享海报功能，保留 Markdown 导出与小组内分享。
- README 项目展示不再包含 Android 端截图。

## Android

本次 Release 附带 Android APK：

- `etime-v1.0.3-release.apk`

由于原 Android 发布密钥在系统重装后丢失，本版本使用新的签名证书。已安装旧版本的用户需要先卸载旧版，再安装本版本；请提前确认重要数据已经同步到服务器。

自律模式需要手动授予 Android“使用情况访问”和“悬浮窗”权限。

## Verification

- 后端复盘、热力图、目标与通知回归测试
- 桌面和移动端复盘、通知弹层视觉检查
- Android Capacitor 同步与 Gradle release 构建
